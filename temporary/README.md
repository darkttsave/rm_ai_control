# Temporary

`temporary/` 是 **Disposable Local Scratch Space**。除本说明外，目录内容由 Git 忽略，并且可以随时丢失。

- 这里不是 Source of Truth，也不是 Artifact 的稳定入站区。
- Manager / Memory Curator 不得让 Current 或 Authoritative Artifact 永久引用这里。
- 需要进入系统的外部 Return 放入 [`../inbox/`](../inbox/)；审查后转入稳定 Current 位置或 [`../archive/returns/`](../archive/returns/)。
- 临时内容成为正式证据前，必须先晋升到 tracked 的稳定位置，再由 Current State 建立引用。
