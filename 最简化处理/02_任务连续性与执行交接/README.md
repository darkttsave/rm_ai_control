# 任务连续性与执行交接

本目录只回答三个问题：

1. 同一角色、同一任务换对话时，怎样继续？
2. 给下游执行体派任务时，怎样控制冷启动和热启动提示词？
3. 项目不变但更换执行体时，项目中必须留下什么？

| 场景 | 使用文件 | 核心对象 |
|---|---|---|
| 换对话，不换任务 | [SAME_TASK_CONTINUATION.md](SAME_TASK_CONTINUATION.md) | 当前任务状态 |
| 给下游派任务 | [EXECUTOR_PROMPT.md](EXECUTOR_PROMPT.md) | 执行边界 |
| 更换执行体 | [EXECUTOR_HANDOFF.md](EXECUTOR_HANDOFF.md) | 项目现场与产物 |

冷启动一个项目或总监督对话不属于这里。已有调参日志或任务日志能够承载进展时，直接使用现有日志，不重复生成阶段汇报。

## 共同裁剪规则

只保留丢失后会改变下一步判断的内容。优先引用项目文件、代码、日志和 Git 状态，不复制完整聊天历史、大段代码或原始日志。

推荐长度是软上限；安全边界、关键约束和验收条件不能为了缩短文本而删除。
