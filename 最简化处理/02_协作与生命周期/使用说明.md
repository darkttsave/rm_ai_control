# 协作与生命周期使用说明

这里不再按“协议、模板、检查点”分类，而是按谁负责什么分类。

## 总监督：1

- [创建分对话](01_总监督/创建分对话.md)：定义分对话的角色、任务、权限、材料入口和上报条件。

分对话建立后，总监督不负责维护它的日常上下文。

## 分对话：3

- [向上游提交任务汇报](02_分对话/向上游提交任务汇报.md)：任务完成、阻塞或需要主线决定时使用。
- [向下游发布执行提示词](02_分对话/向下游发布执行提示词.md)：给执行体发布 Cold Start 或 Warm Start 任务。
- [管理上下文生命周期](02_分对话/管理上下文生命周期.md)：检查上下文健康、重新锚定和同任务换对话。

## 执行体：2

- [反馈执行结果](03_执行体/反馈执行结果.md)：向派发任务的分对话返回一次简洁结果。
- [交接工作现场](03_执行体/交接工作现场.md)：另一执行体将接管同一个项目或工作目录时使用。

## 共同裁剪规则

只保留丢失后会改变下一步判断的内容。优先引用 GitHub、仓库文件、调参手册和任务日志，不复制完整聊天历史、大段代码或原始日志。

推荐长度是软上限；安全边界、关键约束和验收条件不能为了缩短文本而删除。
