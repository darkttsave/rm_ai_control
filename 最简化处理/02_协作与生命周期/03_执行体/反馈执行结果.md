# 反馈执行结果

> 适用角色：执行体  
> 重组来源：`TASK_BRIEF_TEMPLATE.md` 的 Expected Return、`STAGE_CHECKPOINT_TEMPLATE.md`

这是执行体向派发任务的分对话进行的一次纵向反馈。Git 记录代码变化，调参手册或任务日志记录实验过程，本报告只补充结果、验证、风险和下一步。

在任务完成、部分完成或受阻时提交一次即可，不要求持续生成阶段报告。建议控制在 `150～400` 个中文字符。

## 模板

```markdown
# 执行结果反馈

## Outcome
PASS / PARTIAL / FAILED

## Changed
修改内容和可观察行为变化。

## Verification
执行了什么验证，结果如何。

## Not Verified

## Problems / Risks

## Evidence
- Branch / Commit / PR：
- Tuning Manual / Task Log：

## Suggested Next Step
```

简单任务允许删除空字段，但不得把“已修改”写成“已验证”。
