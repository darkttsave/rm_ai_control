# 向上游提交任务汇报

> 适用角色：分对话  
> 重组来源：`STAGE_CHECKPOINT_TEMPLATE.md`、`Carry_Forward.md`

## 何时使用

- 当前任务或阶段已经完成；
- 遇到阻塞，需要总监督决定；
- 目标、范围或重要边界需要改变；
- 新事实会影响项目主线；
- 分对话准备暂停、替换或结束。

不按固定周期汇报。调参过程、测试参数、现象和结论继续写入调参手册或任务日志；上游报告只提炼结果、影响和需要决定的事项。

建议控制在 `300～700` 个中文字符。

## 模板

```markdown
# 任务汇报

## Outcome
PASS / PARTIAL / BLOCKED

## Goal

## Result
只写本轮已经确认的结果。

## Evidence
- GitHub / Git：
- Tuning Manual / Task Log：
- Other：

## Impact on Mainline

## Decision Needed
不需要上游决定时删除。

## Recommended Next Step
```

## 验收

总监督无需读取完整分对话，也能判断结果是否成立、是否影响主线、是否需要做决定。
