# Note Style Standard — 正式笔记格式

> 来源：`protocol/current/RM_AI_Development_Protocol_v2.3_Frozen/playbooks/knowledge/notes/NOTE_STYLE_STANDARD.md`  
> 只约束正式 Knowledge Note，普通讲解不必套用。

## 标题与层级

标题负责定位，正文负责解释。默认使用 `# / ## / ###`，避免把背景和完整结论塞进标题。

## 第一屏

按笔记类型前置最有用的信息：理论笔记恢复模型，API/工程笔记优先可查，系统笔记优先数据或状态流。

## 数学公式

- 先定义符号；
- 说明公式回答什么；
- 近似条件紧邻公式；
- 同一变量保持一致记法。

## 代码

- 代码块标明语言；
- 使用最小可理解示例；
- 注释贴近对应语句；
- 不复制与主线无关的大段源码。

## 图片

图片必须承担明确问题。暂缺图片时写明建议内容及其负责说明的关系，不只写“这里放图”。

## 来源与不确定性

来源事实、模型补充和外部纠错分开。允许明确写 `Unknown`、`待验证`、`当前理解` 或 `来源未明确`。

## 链接

当前笔记先给足继续阅读所需的最小解释，再链接深入材料；链接不能代替解释。

## 语言

直接、清晰、可扫描、少对话式过渡。需要详细时讲清因果，不靠增加句子长度制造“深入”。

## 输出前检查

- [ ] 第一屏可以快速恢复本篇；
- [ ] 主线只有一条；
- [ ] 公式符号与边界已说明；
- [ ] 图和代码承担明确任务；
- [ ] 来源、解释、推断和验证状态已分开；
- [ ] 链接没有替代必要解释；
- [ ] 没有为完整而展开无关知识。
