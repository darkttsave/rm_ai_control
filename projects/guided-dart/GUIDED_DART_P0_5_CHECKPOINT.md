## 3. Verified Progress / Facts

### P0 已完成的系统认知

- 已建立制导镖完整系统链路：

  `比赛/任务状态 → 目标信息 → 发射初始条件 → 飞行 → 状态估计 → Guidance → Control → Actuator → 飞行动力学 → 命中/裁判判定`

- 已明确：
  - Perception / Vision：获取目标相关观测。
  - State Estimation：把传感器测量变成可供决策使用的状态。
  - Guidance：决定“希望飞镖怎样运动”。
  - Control：决定“怎样让飞镖实现所需运动”。
  - Actuation：舵机/舵面等物理执行。
- 已明确 `Measurement ≠ State`。
- 已明确“姿态 ≠ Pose”“姿态方向 ≠ 速度方向”。
- 已明确 Guidance 与 Control 是不同层级，Guidance 输出不能直接等同于舵机角度。

### 2026 规则历史基线

- 已阅读 2026 官方规则并作为历史参考，不把其直接外推为下一赛季规则。

- 已确认 2026 终端移动目标在检测到飞镖发射后 1.2 s 开始移动，并在不超过 600 ms 内完成移动。

### 已形成的团队协作认识

- 制导镖是机电算法强耦合项目。
- 已形成原则：
  - `横向知识要齐，纵向深度可以不同。`

- 已明确不适合采用“机械做完、电控做完、算法做完，最后再集成”的工作方式。

### P0.5 已开始的通用基础内容

已学习：
1. 响应时间、延迟、带宽、饱和
   - 延迟：晚多久开始响应。
   - 响应时间：开始后多久做到。
   - 带宽：系统能有效跟随多快变化的输入。
   - 饱和：系统最多能做到多少。
   - 关键认识：`算法算得快 ≠ 飞镖反应得快`。

2. 姿态、速度方向、轨迹角、攻角
   - Pitch `θ`：机体朝向。
   - 轨迹角 `γ`：速度 / 轨迹方向。
   - 二维简化下机体攻角：`α_b ≈ θ - γ`。
   - 翼面安装角 `i` 与翼面攻角关系：`α_w ≈ θ + i - γ`。
   - 已明确：
     - 姿态 ≠ 速度方向；
     - 姿态变化 ≠ 轨迹立即变化；
     - 控制姿态 ≠ 直接控制命中轨迹。
- 已对用户整理的 AoA 笔记做过纠偏：
  - 正升力不要求 AoA 一定大于 0°；
  - 机体纵轴和翼型弦线不能混为一谈；
  - 尾翼应理解为使系统趋向稳定平衡状态，而不是必然“回到 AoA = 0”。

## 4. Current Understanding / Hypotheses

- 当前更适合把飞镖继续学习定义为“跨方案通用基础探索”，而不是继续逐校完整阅读。
- 对算法成员而言，目前最值得补的是：
  - Control 接口基础；
  - 飞行状态概念；
  - 坐标系与时间；
  - Guidance 的通用思想；
  - 实验与日志体系。
- ROS2 大概率不是镖体核心运行框架，但可能对地面测试、日志、回放、数据分析有价值；其更主要的价值仍是用户长期视觉工程基础能力。
- 第一代制导镖研发的重要产物之一，不只是算法，而是对真实系统能力、延迟、舵效、气动响应等的量化认识。
- Guidance 的可行性必须受 Control + Actuator + Mechanics 的真实能力边界约束。
