# Capability Impact

> 仅在 Checkpoint、Task Report、Specialist Return、Stage Report 或 STATE_UPDATE 涉及长期功能变化时附加。每项写能力名称、证据与索引影响；没有变化只填 `None`。

```text
Capability Impact

Added:
-

Changed:
-

Deprecated:
-

None:
-
```

`Added / Changed / Deprecated` 不等于自动批准。Manager 只在权威实现、验证或 Maintainer / Human 决策支持时更新 `SYSTEM_CAPABILITY_INDEX.md`；否则记录为 Capability Gap。
